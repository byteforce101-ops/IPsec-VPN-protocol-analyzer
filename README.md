An intelligent, end-to-end AI-driven protocol analysis platform capable of automatically analyzing IPsec VPN deployments, inspecting live network packet streams (`.pcap`, `.pcapng`) and router configuration files (`.conf`, `.cfg`), inferring operating modes, classifying encrypted application traffic without decryption, and generating automated security assessment reports with integrated Supabase authentication.

---

## 🌟 Key Capabilities & Features

### a) User Authentication & Access Control
- **Supabase Authentication**: Integrated Email + Password login and user registration powered by `@supabase/supabase-js`.
- **User Profile Management**: Live user session persistence, header profile badge display, and single-click Sign Out.
- **Graceful Local Demo Mode**: Fallback mode allowing seamless local testing and audit exploration even if Supabase keys are not configured yet.

### b) VPN Testbed Generation
- **Variations Supported**:
  - **Operating Modes**: Tunnel Mode vs. Transport Mode
  - **Encryption Ciphers**: AES-128-CBC, AES-256-CBC, AES-128-GCM, AES-256-GCM, 3DES, ChaCha20-Poly1305
  - **Authentication / HMAC**: HMAC-SHA1, HMAC-SHA256, HMAC-SHA384, HMAC-SHA512
  - **Diffie-Hellman Key Exchange Groups**: Group 2 (1024-bit), Group 14 (2048-bit MODP), Group 19 (ECP256), Group 20 (ECP384), Group 21 (ECP521)
  - **Perfect Forward Secrecy (PFS)**: Enabled / Disabled
  - **IP Protocols & Versions**: Dual-stack IPv4 & IPv6 communication, ESP (IP proto 50), AH (IP proto 51)
  - **Encrypted Application Traffic Types**: VoIP (audio calls), WhatsApp (chat messaging), E-mail (SMTP/IMAP), Web Browsing (HTTPS), ICMP (Heartbeats), Video Streaming, File Transfer (SFTP/FTP)

### c) Traffic & Packet Capture Engine
- Supports PCAPs generated by Wireshark, `tcpdump`, or custom Scapy synthetic packet generators.
- Automated extraction of IKEv1/IKEv2 negotiation handshakes, ESP payloads, AH headers, and Security Parameter Index (SPI) attributes.

### d) AI-Based Encrypted Traffic & Protocol Identification
- **AI Classification Engine**: Trained model utilizing statistical flow features (packet size distribution, mean, std deviation, min/max payload, burst dynamics) to dynamically predict application traffic inside encrypted ESP flows with **94%+ accuracy**.
- **Identifies**:
  - IPsec Protocol (ESP / AH)
  - IKE Version (IKEv1 / IKEv2)
  - Operating Mode (Tunnel / Transport)
  - Encryption & Authentication Algorithms
  - Key Exchange Method & DH Groups
  - Security Association (SA) attributes (SPIs, Lifetimes, Replay Windows)

### e) Comprehensive Security Assessment & Risk Scoring
- Automated audit against **NIST SP 800-77 Rev 1**, **NSA CNSA Suite**, and **RFC 7296** best practices.
- Evaluates Cryptographic Strength, Pre-Shared Key (PSK) Entropy, Aggressive Mode Identity Exposure (Metadata Leakage), Perfect Forward Secrecy (PFS), Transport Mode Metadata Risks, and Replay Protection.

### f) Executive & Technical Reporting Deliverables
- **Interactive Next.js Dashboard**: Multi-tab interface featuring Overview, Protocol Parameters, AI Classifier, and Threat Matrix styled in a modern, light-theme palette (`#f6f7fb` + `#5850ec`).
- **Automated PDF Executive Report**: Jinja2 & WeasyPrint PDF report renderer.
- **CLI Tool**: Terminal command-line auditor (`scripts/cli.py`).
- **Resilient Backend Startup**: Auto-detects port availability to prevent socket binding conflicts (`[WinError 10048]`).

## 🚀 Quick Start Guide

### 1. Prerequisites & Environment Setup
- Python 3.10+
- Node.js 18+ and `pnpm`

```bash
# Clone the repository
git clone https://github.com/byteforce101-ops/IPsec-VPN-protocol-analyzer.git
cd IPsec-VPN-protocol-analyzer

# Initialize Python Virtual Environment & Install Dependencies
python -m venv backend/venv
.\backend\venv\Scripts\activate
pip install -r backend/requirements.txt

# Install Node.js dependencies
pnpm install
```

### 2. Configure Supabase Credentials (Optional)
To connect your own Supabase backend, open or create `.env.local` in the project root and add your project credentials from the [Supabase Console](https://supabase.com/dashboard):

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-supabase-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```
*(If left as template placeholders, the app automatically runs in **Local Demo Mode**.)*

### 3. Train the AI Classification Model & Generate Testbed PCAPs
```bash
# Generate the training dataset (2,100 samples)
python backend/ai/dataset_generator.py

# Train the AI Traffic Classifier (94%+ test accuracy)
python backend/ai/train_model.py

# Generate testbed sample PCAPs & configs
python scripts/generate_sample_pcaps.py
```

### 4. Running the System

#### Option A: One-Click Launch (Windows Batch)
Double-click `start_all.bat` or run:
```cmd
start_all.bat
```

#### Option B: Manual Terminal Launch
**Terminal 1 (FastAPI Backend)**:
```bash
.\backend\venv\Scripts\python.exe backend/main.py
```
*(Backend auto-detects and binds to `http://127.0.0.1:8000` or the next free port)*

**Terminal 2 (Next.js Dashboard Frontend)**:
```bash
pnpm dev
```
*(Frontend UI runs on `http://localhost:3000`)*

#### Option C: Running the CLI Analysis Tool
```bash
python scripts/cli.py samples/ikev2_aes256_pfs_secure.pcap
```
